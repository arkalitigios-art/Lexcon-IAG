# 020. Transición visible de estudio aprobado a CDP

- Estado: aceptada
- Fecha: 2026-09-30

## Contexto

Después de la aprobación jurídica, la IE necesita identificar con claridad que debe cargar el CDP y conocer si la comunicación institucional fue entregada, preparada o requiere configuración.

## Decisión

La ficha del expediente expone para rectoría y apoyo una tarjeta específica durante la fase de disponibilidad presupuestal. Consulta la última salida de correo de aprobación, muestra su estado sin simular una entrega externa y enlaza directamente con la actuación de carga del CDP.

## Consecuencias

La IE dispone de una transición visible desde la aprobación del estudio hacia el CDP. La ausencia de un proveedor de correo no bloquea el expediente ni se presenta como un correo entregado.
